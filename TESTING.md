# Тестирование «Моей памяти»

## Бесплатный запуск

Тесты выполняются локально и в GitHub Actions, без платных API и без внешней AI-модели.

Команды: `gradle --no-daemon testDebugUnitTest` и `gradle --no-daemon assembleDebug`.

## Что проверяется сейчас

`CalendarRules` и `EventStorage` — общая чистая логика календарной сетки и локального хранения событий, которую использует главный экран и проверяют JUnit-тесты:

- смещение первого дня месяца при неделе с понедельника;
- число ячеек календаря (только полные недели);
- соответствие ячейки числу месяца;
- пустые ячейки до/после месяца;
- допустимость числа месяца;
- високосный февраль;
- полный перебор месяцев за 2024–2032 годы;\n- сохранение и восстановление событий;\n- русские заголовки, emoji и разделители в названиях;\n- игнорирование повреждённых и неподдерживаемых записей.

## Что пока не проверяется и требует следующих этапов

По текущей реализации `MainActivity.kt`:

- стартовый месяц пока задан вручную как ноябрь 2026 года;
- события календаря сохраняются в SharedPreferences через версионированный формат `EventStorage`; round-trip, русские названия, спецсимволы и некорректные записи покрыты JVM-тестами;
- повторяющееся событие отображается как признак, но полноценное правило повторения и расчёт ближайшей даты ещё не реализованы;
- реальные системные уведомления и напоминания ещё не подключены;
- тестируется сериализация/десериализация событий, но автоматический Android UI-тест реального закрытия и повторного запуска приложения ещё не добавлен.

Эти пункты нельзя считать реализованными только потому, что календарные unit-тесты проходят.

## Критерий готовности текущего этапа

GitHub Actions должен успешно выполнить `testDebugUnitTest`, затем собрать debug APK. Успешный коммит или наличие workflow ещё не заменяет фактический зелёный результат запуска.
