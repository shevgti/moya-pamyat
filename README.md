# Моя память

Отдельный Android-проект. Не связан с FotoPoryadok.

## Текущий этап
- Kotlin + Jetpack Compose
- Главный экран с разделами: Память, Задачи, Чаты, Финансы, Друзья, Календарь
- Добавление записей в разделы
- Отметка выполненных задач
- Удаление записей
- Переключение светлой и тёмной темы
- GitHub Actions workflow для автоматической сборки debug APK

## Важно
Пока записи хранятся только в оперативном состоянии приложения и пропадают после его полного закрытия. Постоянное локальное хранение, напоминания, реальные чаты и синхронизация будут добавлены отдельными этапами.

Оригинальные макеты нужно добавить отдельно в `design/`. Они не заменяются и не перерисовываются автоматически.
